Try it on the PayPal sandbox.

Everything below is the working app: a wallet that issues ScopePay codes, two shops that accept them, and the evidence trail behind every payment.

  1. Link PayPalIn the Wallet tab, link a sandbox buyer once (the account ending @personal.example.com).
  2. Generate a codeSet a cap, an expiry and optionally lock it to one shop. Copy the code.
  3. Shop and payOpen Greenleaf Grocer, fill a basket, paste the code and press Fast Pay.
  4. Break a ruleGo over the cap or use the code at Northside. Open the evidence record to see why it was declined.
